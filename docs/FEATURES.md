# Fidget 功能规格

本文描述每个功能的行为、默认值与边界，是实现与测试的共同依据。

## 1. 核心：闲时移动鼠标

| 项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 闲置阈值 `idleThresholdSeconds` | 60 s | 5 s – 2 h | 用户真实输入停止多久后开始移动 |
| 移动间隔 `jiggleIntervalSeconds` | 60 s | 5 s – 2 h | 闲置期间每隔多久移动一次；达到阈值的瞬间立即移动一次 |
| 轨迹 `pattern` | 轻推 | 轻推 / 圆 / 方 / 8 字 / 随机游走 | 轻推与方形方向逐次交替，避免漂移 |
| 距离 `amplitude` | 8 px | 1 – 300 px | 离起点的最大距离 |
| 时长 `durationMilliseconds` | 300 ms | 50 – 3000 ms | 一次移动的总时长；每秒 60 个采样点，2 – 240 步 |
| 回到原位 `returnToOrigin` | 开 | | 圆与 8 字天然回到原点 |
| 隐形模式 `invisibleMode` | 关 | | 强制 1 px、50 ms、回到原点，肉眼不可察觉但足以重置闲置计时 |

行为细节：

- 只有**真实**输入会让状态回到“监测中”；Fidget 自己的移动不算（见架构文档 §3）。
- 起点距屏幕边缘不足 `amplitude + 2` px 时向内收，避免反复触碰角落触发“触发角”；轨迹点都裁剪在所在显示器内。
- 多显示器：以指针所在显示器的边界为准。
- 每次移动后读回指针位置；若整段轨迹指针都没动，计一次失败，连续 2 次在面板显示警告并提示检查权限（可在高级设置关闭校验）。
- 系统睡眠/唤醒后状态机自然恢复；唤醒后若屏幕锁定则按锁屏规则暂停。

## 2. 启用与暂停

- 总开关：面板上的大开关、右键菜单、全局快捷键、`fidget://enable|disable|toggle`。
- 手动暂停预设：15 分钟、30 分钟、1 小时、2 小时、4 小时、今天剩余时间（到次日 0:00）、直到手动恢复。
- 定时暂停到期自动恢复；面板与菜单栏显示“暂停至 HH:mm”。
- 快捷键按下时：若处于手动暂停 → 恢复；否则切换启用/停用。

## 3. 智能暂停规则（优先级从高到低）

1. **锁屏 / 屏保 / 会话切出 / 系统睡眠**（默认开）——移动没有意义。
2. **电池供电**（默认关）。
3. **计划表**（默认关）：星期集合 + 开始/结束时间；结束 ≤ 开始表示跨午夜窗口，归属开始日；开始 = 结束表示全天。面板显示下次恢复时间。
4. **应用列表**（默认空）：模式“运行中”或“最前”。可从 `/Applications` 选择或从运行中的应用添加，显示应用图标。
5. **其它应用阻止显示器休眠**（默认关）：视频播放、演示、通话时常见；诊断里列出持有者。

## 4. 防休眠（可选，默认关）

- 阻止显示器休眠 / 阻止系统休眠，底层是 IOPM 断言。
- 仅在“监测中/工作中”持有；停用、暂停、退出时释放。

## 5. 菜单栏与面板

- 图标按状态变化：工作中 / 监测中 / 暂停 / 需要权限 / 已关闭（关闭态半透明）。五种图标风格可选（光标、鼠标、闪电、眼睛、圆点）。
- 可选在图标旁显示倒计时（距开始移动或距下一次移动）。
- 左键：弹出面板——状态胶囊、大开关 + 一句话状态、进度条、权限/警告横幅（权限横幅带“重置权限”链接）、暂停菜单/恢复、立即移动、今日/累计/工作时长统计、设置/关于/退出。
- 右键：快捷菜单（启用/停用、暂停子菜单、立即移动、设置、关于、退出）。
- 面板内支持 ⌘, 打开设置、⌘Q 退出。

## 6. 设置窗口（侧边栏六分区）

外观参考 CleanMyMac：接近中性的底色上只有一团淡淡的主题色光晕；每个分区有自己的主题色（通用紫、移动蓝、计划粉、智能暂停绿、防休眠橙、高级靛蓝），侧边栏图标、页头大图标、开关、滑杆和选中态都用它，切换分区时光晕颜色随之过渡。设置分组放在卡片里（深色外观下是半透明的玻璃，浅色外观下是带一点阴影的白卡片），每行左侧有主题色小图标。

有浅色和深色两套配色。“通用”里的“外观”可选跟随系统（默认）、浅色、深色，作用于整个应用：设置、引导与关于窗口、弹出面板和菜单；菜单栏图标跟随菜单栏，不受影响。

侧边栏顶部是应用图标与版本，底部是当前状态（工作中、监测中等，悬停显示详情）和总开关。

| 分区 | 内容 |
| --- | --- |
| 通用 | 登录时启动（含“需要批准”提示）、图标风格、倒计时、全局快捷键录制、外观（跟随系统 / 浅色 / 深色）、语言（跟随系统 / English / 简体中文，即时生效）、权限状态、重置权限与引导入口 |
| 移动 | 页头右侧“立即移动”与上次结果；阈值与间隔（对数滑杆 + 预设菜单）、轨迹预览（点阵画布上的发光轨迹与光点）与五张轨迹卡片、距离、时长、回到原位、隐形模式 |
| 计划 | 启用、星期圆点选择（跟随系统的一周起始日）、起止时间、跨午夜提示、下次生效时间 |
| 智能暂停 | 三条系统规则、应用列表与模式 |
| 防休眠 | 两张功能卡片（显示器 / 系统，各带一句说明）与当前持有状态 |
| 高级 | 四张统计卡片与重置、诊断信息（权限、系统/真实闲置、引擎状态、锁屏、电池、断言、持有者、上次移动）与一键拷贝、文件日志、设置导入/导出/显示/恢复默认、版本与检查更新 |

窗口默认 860×640，最小 780×520；最小尺寸下英文界面也不截断文字（标题换行，控件保持完整）。

## 7. 首次引导

四步：介绍 → 授予辅助功能权限（实时检测，已授权后显示 ✓；开关已开却仍未授权时可“重置权限”）→ 常用偏好（登录启动、阈值、隐形模式、锁屏规则）→ 完成（可立即试一次移动）。
未完成引导或权限缺失时启动即显示；也可从设置重新打开。引导与关于窗口和设置窗口同一风格，引导每一步换一种主题色。

## 8. 自动化接口

URL scheme `fidget://`：`enable` `disable` `toggle` `pause[?minutes=N]` `resume` `move` `settings` `setup`。
例如 `open "fidget://pause?minutes=30"`；`settings` 可带 `?section=movement` 直达分区。
收到 SIGTERM（例如 `killall Fidget`）时走正常退出流程：保存设置与统计、释放电源断言。

## 9. 本地化

英文与简体中文，所有界面文案走 `L.t`/`L.f`；测试保证两种语言键集合一致且代码里用到的键都存在。

## 10. 非功能

- 零网络访问、零账号、零第三方依赖。
- 1 Hz 轮询，昂贵查询（运行中的进程列表、其他进程的断言列表）仅在相应规则开启时执行并缓存 5 s。
- 看不见的界面不消耗资源：关闭的窗口和收起的面板会释放 SwiftUI 内容；菜单栏图标只在显示内容变化时重绘；统计文件只在内容变化时写入。
- Swift 6 严格并发，无数据竞争警告。
- 仅 arm64；Info.plist 声明 `LSArchitecturePriority`/`LSRequiresNativeExecution`。
- 支持 macOS 11 Big Sur 及以上（Apple Silicon 能运行的全部系统）。macOS 11 上鼠标样式的菜单栏图标（需要 macOS 12 的符号）不提供，其余功能一致；macOS 11–12 的登录启动用 LaunchAgent 实现，不出现在系统的登录项列表里。
