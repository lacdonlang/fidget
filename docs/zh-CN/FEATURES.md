# 功能规格

[English](../en/FEATURES.md) · **简体中文**

每个功能的行为、默认值与边界，是实现与测试的共同依据。

## 闲时移动

| 设置 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 闲置阈值 `idleThresholdSeconds` | 60 秒 | 5 秒 – 2 小时 | 真实输入停止多久后开始移动 |
| 移动间隔 `jiggleIntervalSeconds` | 60 秒 | 5 秒 – 2 小时 | 闲置期间每隔多久移动一次；达到阈值时立即移动第一次 |
| 轨迹 `pattern` | 轻推 | 轻推 / 圆 / 方 / 8 字 / 随机游走 | 轻推与方形逐次换方向，指针不会越移越远 |
| 距离 `amplitude` | 8 px | 1 – 300 px | 离起点的最大距离 |
| 时长 `durationMilliseconds` | 300 ms | 50 – 3000 ms | 一次移动的时长，每秒 60 个采样点（2 – 240 步） |
| 回到原位 `returnToOrigin` | 开 | | 圆与 8 字总会回到起点 |
| 隐形模式 `invisibleMode` | 关 | | 强制 1 px、50 ms 并回到原位：肉眼看不出，但足以重置闲置计时 |

- 只有**真实**输入会让 Fidget 回到“监测中”，它自己的移动不算（见[架构设计](ARCHITECTURE.md)）。
- 起点靠近屏幕边缘时向内收，避免触发“触发角”；轨迹点都限制在指针所在的显示器内。
- 每次移动后读回指针位置；连续两次指针都没动时显示警告，提示检查权限（可在“高级”里关闭这项校验）。

## 开关与暂停

- 总开关：面板、右键菜单、全局快捷键，或 `fidget://enable|disable|toggle`。处于手动暂停时按快捷键会恢复，否则切换开关。
- 暂停预设：15 分钟、30 分钟、1 小时、2 小时、4 小时、今天剩余时间（到午夜）、直到手动恢复。定时暂停到期自动恢复，面板会显示恢复时间。

## 智能暂停（优先级从高到低）

1. **锁屏、屏保、切换用户或系统睡眠**（默认开）。
2. **电池供电**（默认关）。
3. **计划表**（默认关）：星期加起止时间。结束时间不晚于开始时间表示跨午夜，归属开始那天；起止相同表示全天。面板显示何时恢复。
4. **应用**（默认无）：列表中的应用运行时暂停，或仅在它位于最前时暂停。
5. **其他应用阻止显示器休眠**（默认关）：播放视频、演示、通话时常见，诊断信息里会列出是哪些应用。

## 防休眠（可选，默认关）

用 IOKit 电源断言阻止显示器和/或系统休眠。只在“监测中”和“工作中”持有，关闭、暂停或退出时释放。

## 菜单栏与面板

- 图标反映状态：工作中、监测中、已暂停、需要权限、已关闭（半透明）。有五种图标风格可选，图标旁还可以显示倒计时。
- 点击图标弹出面板：状态、总开关、进度、权限与警告横幅（带“重置权限”）、暂停与恢复、“立即移动”、统计，以及设置、关于、退出。⌘, 打开设置，⌘Q 退出。
- 右键弹出快捷菜单，包含同样的主要操作。

## 设置窗口

外观参考 CleanMyMac：每个分区有自己的主题色，底色上一团淡淡的光晕随分区切换而过渡。**设置 → 通用 → 外观**（跟随系统 / 浅色 / 深色）作用于整个应用；菜单栏图标跟随菜单栏。窗口默认 860×640，最小 780×520，最小尺寸下英文界面也不截断文字。

| 分区 | 内容 |
| --- | --- |
| 通用 | 登录时启动、图标风格、倒计时、全局快捷键、外观、语言（跟随系统 / English / 简体中文，即时生效）、权限状态、重置权限、引导 |
| 移动 | 立即移动、阈值与间隔、轨迹预览与卡片、距离、时长、回到原位、隐形模式 |
| 计划 | 开关、星期（一周起始日跟随系统）、起止时间、下次生效时间 |
| 智能暂停 | 系统规则、应用列表及其模式 |
| 防休眠 | 显示器休眠与系统休眠，以及当前是否持有断言 |
| 高级 | 统计、诊断信息与一键拷贝、文件日志、设置的导入 / 导出 / 恢复默认、更新 |

## 首次引导

四步：介绍 → 授予辅助功能权限（实时检测；开关已开却不生效时可“重置权限”）→ 常用偏好 → 完成（可以试移动一次）。引导完成前或缺少权限时启动即显示，也可以从设置里重新打开。

## 自动化

URL scheme `fidget://`：`enable`、`disable`、`toggle`、`pause[?minutes=N]`、`resume`、`move`、`settings[?section=movement]`、`setup`。收到 SIGTERM（例如 `killall Fidget`）时正常退出：保存设置与统计，释放电源断言。

## 在线更新

- 用 Sparkle 2.9.x 每天检查一次 `https://github.com/lacdonlang/fidget/releases/latest/download/appcast.xml`，并显示取自更新日志的更新说明。
- 更新说明跟随应用的界面语言：默认跟随系统，也可以在**设置 → 通用 → 语言**里手动选择。中文界面读 `appcast.zh-CN.xml`，其他语言读 `appcast.xml`；切换语言后，下一次检查生效。
- **设置 → 高级 → 更新**：自动检查更新（默认开）、自动下载并安装（默认关；Fidget 退出时安装）、“检查更新…”与上次检查时间。
- 更新包的 EdDSA 签名必须对得上 `Info.plist` 里的 `SUPublicEDKey`，还必须满足已安装版本的代码签名要求（同一开发者、同一 bundle ID），所以更新后辅助功能授权依然有效。
- 调试构建与 `swift run` 不检查更新，“检查更新…”改为打开发布页。

## 非功能

- 英文与简体中文；界面文案都经过 `L.t` / `L.f`，测试保证两种语言的键一致。
- 无需账号；唯一的联网是检查更新，可以关闭。唯一的第三方依赖是 Sparkle。
- 每秒轮询一次；昂贵的查询（运行中的应用、其他进程持有的断言）只在相应规则开启时执行，并缓存 5 秒。关闭的窗口和收起的面板会释放 SwiftUI 内容。
- Swift 6 严格并发检查，仅 arm64。
- 支持 macOS 11 及以上。macOS 11 上不提供鼠标样式的菜单栏图标（它的符号需要 macOS 12）；macOS 11–12 的登录启动用 LaunchAgent 实现，不会出现在系统的登录项列表里。
