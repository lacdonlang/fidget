# 测试

[English](../en/TESTING.md) · **简体中文**

## 测试分层

| 层 | 覆盖内容 | 手段 | 运行环境 |
| --- | --- | --- | --- |
| FidgetCore | 状态机、轨迹、计划表、设置解码与校验、统计、命令解析 | Swift Testing：纯值类型 + 固定时区日历 + `EngineSim` 时间线模拟器 | 任何 Mac，无需权限 |
| FidgetSystem | 每个系统适配器能跑通、不崩溃、边界行为正确 | 集成测试直接调用 macOS API；需要辅助功能权限的用例用 `#require` 跳过 | 本机或 CI 的 GUI 会话 |
| FidgetApp | 状态到文案与图标的映射、驱动与模型的协作、本地化、在线更新 | 用内存存储与假指针驱动 `EngineDriver`；扫描源码校验字符串键 | 任何 Mac |
| 界面 | 菜单栏面板真实弹出后的位置 | `make ui-test`（设置 `FIDGET_UI_TESTS=1`；会抢走焦点，默认跳过） | 本机 GUI 会话 |
| 端到端 | 打包后的应用能启动并真实移动指针；各窗口能渲染 | `make smoke`（终端需有辅助功能权限）与 `make screenshots` | 本机 |

## 运行

```bash
swift test                            # 全部
swift test --filter FidgetCoreTests   # 仅核心层
make ui-test                          # 真实弹出菜单栏面板
make check-min-os                     # 按 macOS 11 做类型检查
```

- CI（`.github/workflows/ci.yml`）在 Apple Silicon 上用 `scripts/select-xcode.sh` 选出的 Xcode 执行 `swift build`、`swift test`、`STRICT_MIN_OS=1 scripts/build-app.sh` 与 `scripts/verify-app.sh`。
- 本地的 Xcode 27 只按 macOS 12 检查 API 可用性，改动界面或系统层后请运行 `make check-min-os`。
- `make smoke` 直接运行 `.app` 里的可执行文件（而不是用 `open`），进程因此继承终端的辅助功能授权。
- `make screenshots` 按语言（`en`、`zh-CN`）与外观（`dark`、`light`）各渲染一套，输出到 `docs/images/<语言>/<外观>/`；在进程内渲染，不需要任何权限。窗口存为 JPEG，弹出面板存为 PNG。改动界面后看一遍。

## 测试内容

- **核心层**：设置的默认值、回退与范围收敛；计划表边界与跨午夜；轨迹的上下限与角落安全；引擎的每种状态转换，包括自己的移动不算真实输入、暂停、规则优先级与失败警告。
- **系统层**：每个适配器直接调用真实 API，包括真实移动 1 px（需权限）、损坏文件备份，以及 macOS 11–12 的 LaunchAgent 登录项。
- **应用层**：状态展示、用假服务跑通 `EngineDriver` 的完整回路、SF Symbols 在 macOS 11 上可用、两种语言的键一致。
- **在线更新**：`Info.plist` 里的更新源与公钥；`scripts/make-appcast.sh` 生成的两份清单（版本、构建号、最低系统、下载地址、签名、中英文更新说明），任一份更新日志缺少当前版本时失败；中文界面读 `appcast.zh-CN.xml`。

## 发布前手动验收

0. 在能拿到的最旧系统上重复本清单（macOS 12 可以装在 Apple Silicon 的虚拟机里），重点看设置窗口布局、菜单栏图标与登录启动。
1. 全新用户：出现引导；授权后面板由“需要权限”变为“监测中”，“立即移动”能移动指针。开关已开却仍未授权时，“重置权限”能恢复。
2. 面板完整地挂在菜单栏图标下方，横幅出现或消失后依然如此。
3. 设置：切换分区时颜色随之变化；“外观”在跟随系统、浅色、深色之间即时切换；按住窗口顶部能拖动；最小尺寸下文字不截断；下拉菜单能打开并标出当前选项；起止时间能用键盘修改。
4. 阈值设为 10 秒后离开鼠标：指针按所选轨迹移动并回到原位；倒计时正确；Slack 保持在线。
5. 碰一下鼠标：立刻回到“监测中”。
6. 锁屏或启动屏保：暂停；解锁后恢复。
7. 计划表不包含当前时间：显示不在计划时段，以及何时恢复。
8. 把最前的应用加入规则：“运行中”与“最前”两种模式都正确。
9. 开启“阻止显示器休眠”：`pmset -g assertions` 能看到 Fidget 的断言，关闭后消失。
10. 全局快捷键、即时切换语言、导入导出设置、重置统计。
11. 重启应用后设置与统计保留，登录项状态与系统一致。新版本发布后，旧版本用“检查更新…”能找到并安装它，安装后自动重启、辅助功能授权仍在，更新说明是应用当前的语言。
12. `open "fidget://pause?minutes=1"`：一分钟后自动恢复。
