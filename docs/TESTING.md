# Fidget 测试策略

## 1. 分层

| 层 | 目标 | 手段 | 运行环境 |
| --- | --- | --- | --- |
| FidgetCore | 状态机、轨迹、计划表、设置解码/校验、统计、命令解析 | Swift Testing，纯值类型 + 固定时区日历 + `EngineSim` 时间线模拟器 | 任何 macOS，无需权限 |
| FidgetSystem | 每个系统适配器能跑通、不崩溃、边界行为正确 | 集成测试直接调用 macOS API；需要辅助功能权限的用例用 `#require` 跳过 | 本机 / CI 的 GUI 会话 |
| FidgetApp | 状态→文案/图标映射、驱动与模型的协作、本地化完整性 | 用内存存储与假指针控制器驱动 `EngineDriver`；扫描源码校验字符串键 | 任何 macOS |
| 界面 | 菜单栏面板真实弹出后的位置 | `make ui-test`：设置 `FIDGET_UI_TESTS=1` 后才运行，在菜单栏放图标、弹出面板并读取窗口位置；默认跳过，因为会抢走焦点 | 本机 GUI 会话 |
| 端到端 | 打包后的 .app 能启动并真实移动指针；各窗口能渲染 | `make smoke`（`scripts/smoke-test.sh`，终端需有辅助功能权限）与 `make screenshots`（调试构建在进程内用示例数据渲染 `docs/images/` 下的截图，每种语言、每种外观各一套，不需要任何权限；改动界面后看一遍） | 本机 |

## 2. 运行

```bash
swift test                                   # 全部
swift test --filter FidgetCoreTests          # 仅核心层
swift test --filter "引擎状态机"               # 按套件名
make ui-test                                 # 真实弹出菜单栏面板（默认跳过的界面测试）
```

CI（`.github/workflows/ci.yml`）在 Apple Silicon runner 上用 `scripts/select-xcode.sh` 选出能部署到 macOS 11 的 Xcode，执行 `swift build`、`swift test`、`STRICT_MIN_OS=1 scripts/build-app.sh` 与 `scripts/verify-app.sh`（检查产物并实际启动）。

本地的 Xcode 27 只能部署到 macOS 12，`swift build` 会按 12 检查 API 可用性。改动界面或系统层后运行 `make check-min-os`：它直接用 swiftc 按 macOS 11 对全部模块与测试做类型检查，任何“只在新系统上才有”的调用都会报错。

冒烟测试直接运行 `.app` 里的可执行文件（而不是 `open`），这样进程继承终端的辅助功能授权，能真的移动指针。

## 3. 核心层用例清单

- 设置：默认值合法；JSON 往返；缺失键/类型错误/空对象回退默认；越界收敛；应用规则去重；隐形模式有效参数。
- 计划表：关闭恒为真；窗口边界含/不含；周末排除；跨午夜归属开始日；开始=结束为全天；下次恢复（同日/次日/跨周末/当前即在窗口内）；无工作日返回 nil；星期排序。
- 轨迹：五种图案都不超振幅；回到原点语义；步数与时长关系与上下限；隐形模式点数与距离；轻推方向交替；随机游走可复现；角落安全与裁剪；无边界不裁剪；总时长。
- 指针执行器：逐点移动并报告成功；指针不动报告失败；关闭校验恒成功。
- 引擎：off 释放断言；权限缺失阻塞；watching→active 与首次立即移动；合成事件不算真实输入、按间隔重复；真实输入重置；移动进行中不叠加；定时暂停到期自动清除；无限期暂停；规则优先级；应用“最前”模式；断言只在工作中持有；连续失败警告与清零；立即移动无视状态、只执行一次且同样被识别为合成事件；启动时已闲置立即 active。
- 统计、暂停预设、快捷键显示/合法性/编解码、倒计时格式化与刻度取整、URL 命令解析与拒绝。

## 4. 系统层用例清单

空闲时间；指针位置与显示器边界；真实移动 1 px（需权限）；电源断言创建/释放/幂等；电源来源与断言探测；锁屏查询与环境快照；运行中应用与 .app 读取；文件存储往返/缺失/损坏备份；文件日志开关；Carbon 修饰键映射与热键注册/注销/非法拒绝；登录项在非 .app 环境降级；macOS 11–12 的 LaunchAgent 登录项（开启/关闭/幂等、内容按 bundle id 打开、plutil 校验）；权限查询。

## 5. 应用层用例清单

- `StatusPresentation`：每种状态的种类/标题/图标/倒计时；暂停原因文案；图标风格表。
- `EngineDriver`：用假服务跑完整回路——阈值后产生移动、统计递增、指针不动产生警告、暂停/恢复/toggle、电源断言跟随状态、立即移动、`setNeedsTick` 合并重算；每秒的 tick 只通知运行数据（`model.live`），设置界面不随之重算。
- SF Symbols：源码里的每个符号在 macOS 11 上存在，或登记了 macOS 11 就有的替代品并经 `Symbols.name` 使用；替代逻辑；当前系统可用的图标样式。
- 在线更新：Info.plist 的更新源与公钥；`scripts/make-appcast.sh` 生成的 appcast（版本、构建号、最低系统、下载地址、签名属性、更新说明，CHANGELOG 缺少当前版本时失败）。
- 菜单栏面板（`make ui-test`）：真实弹出后挂在菜单栏下方、不超出屏幕；横幅消失、面板变矮后仍然如此。
- 本地化：用系统属性列表解析器读取各语言 strings，键集合与占位符数量一致；源码中每个 `L.t("…")`/`L.f("…")` 的键都存在；界面语言对应的区域设置（语言取覆盖值、地区沿用系统）。

## 6. 手动验收清单（发布前）

0. 在能拿到的最旧系统上（macOS 12 可在 Apple Silicon 的虚拟机里装）重复下面的清单，重点看设置窗口布局、菜单栏图标、登录启动。
1. 全新用户：首次启动出现引导 → 授权 → 面板状态由“需要权限”变为“监测中”，“立即移动”能移动指针。系统设置里开关已开却仍显示未授权时，“重置权限”后重新打开开关即可恢复。
2. 点菜单栏图标：面板完整地挂在图标下方（1.1.0 在 macOS 27 上伸出了屏幕顶端），出现或消失横幅后仍挂在图标下方。
3. 打开设置：切换分区时光晕与控件颜色随之变化；“外观”在跟随系统、浅色、深色之间切换时，设置窗口与弹出面板立即跟着变；按住窗口顶部能拖动窗口；缩到最小尺寸时文字不被截断；下拉菜单（语言、时长预设）能打开且标出当前选项；起止时间能用键盘修改。
4. 设阈值 10 s，手离开鼠标：10 s 后光标按所选轨迹移动并回到原位；菜单栏倒计时正确；Slack 状态保持在线。
5. 碰一下鼠标：状态立刻回到“监测中”，计数清零。
6. 锁屏/屏保：状态变为“已暂停 · 屏幕已锁定”；解锁后恢复。
7. 计划表设成不包含当前时间：显示“不在计划时段 · XX 恢复”。
8. 添加当前最前应用到规则并切换模式：运行中/最前两种模式行为正确。
9. 开启“阻止显示器休眠”：`pmset -g assertions` 能看到 Fidget 的断言；停用后消失。
10. 全局快捷键切换启用；语言切换即时生效；导出/导入设置；重置统计。
11. 重启应用：设置与统计保留；登录项状态与系统一致。发布新版本后，旧版本“检查更新…”能看到它，安装后自动重启、辅助功能授权仍在。
12. `open fidget://pause?minutes=1`：一分钟后自动恢复。
